# AI Data Guard

機密データをクラウドAIへ直接渡さず、ローカル処理・匿名化・構造抽出を強制するためのアプリケーション構想です。

## 現在の状態

このリポジトリの初期版は **公開UIプレビュー専用** です。
実データの入力・ファイル読込・外部AI接続は実装していません。

- スマホ縦型UI
- PWA対応
- 架空データによるローカル検査 / 匿名化 / AI相談用変換のデモ
- CSP `connect-src 'none'`
- 外部フォント・CDN・Analytics・Telemetryなし
- GitHub Pages向けの静的構成

## 重要

GitHub Pages版は公開プレビューです。顧客データ、売上、商品単価、仕入、ツケ、未収金額、PIIその他の実データを入力しないでください。

本番版では、公開Web版と実データ処理版を分離します。実データ処理版はローカル配布アプリとし、外部ネットワーク権限自体を持たせない方向で設計します。

## 予定

1. ローカルファイル読込（本番ローカル版のみ）
2. PII / 財務項目の検出
3. Masking / Redaction / Pseudonymization
4. SQLiteによるローカル状態管理
5. ローカルOCR / ローカルEmbedding / Local RAG
6. Local LLM連携
7. クラウドAIを使う場合の「構造だけ」生成
8. 外部送信前の強制ブロックと明示承認フロー
