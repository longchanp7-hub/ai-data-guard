# AI Data Guard

機密データをクラウドAIへ直接渡さず、ローカル処理・安全確認・匿名化をアプリ側で強制するためのプロジェクトです。

## 想定利用者

AI初心者を前提にしています。

- Excelを日常的に使い、簡単な関数は扱える
- PowerPointを使える
- AGENTS.md、API、JSON、モデル設定、RAG等のAI専門設定はできない / しない
- セキュリティ設定を利用者自身に判断させない

そのため、UIはOffice系アプリに近い感覚で、**ファイルを選ぶ → 安全チェック → 安全な形へ変換 → AIへ相談** の順番で進める設計にします。

専門用語は内部実装に閉じ込め、利用者向け画面では「匿名化」より「名前や電話を隠す」、「データ構造抽出」より「AIに聞く内容を作る」のような表現を優先します。

## 現在の状態

このリポジトリの初期版は **公開UIプレビュー専用** です。
実データの入力・ファイル読込・外部AI接続は実装していません。

- スマホ縦型UI
- PWA対応
- 架空データによる安全チェック / 情報を隠す / AI相談文生成のデモ
- CSP `connect-src 'none'`
- 外部フォント・CDN・Analytics・Telemetryなし
- GitHub Pages向けの静的構成

## 重要

GitHub Pages版は公開プレビューです。顧客データ、売上、商品単価、仕入、ツケ、未収金額、PIIその他の実データを入力しないでください。

本番版では、公開Web版と実データ処理版を分離します。実データ処理版はローカル配布アプリとし、外部ネットワーク権限自体を持たせない方向で設計します。

## 予定

1. Excel / CSVのローカル読込
2. 氏名、電話番号、住所、金額等の自動検出
3. 利用者向けには「安全チェック」として表示
4. Masking / Redaction / Pseudonymizationはアプリ内部で実行
5. SQLiteによるローカル状態管理
6. ローカルOCR / Embedding / RAGは必要時のみ裏側で利用
7. Local LLMがある環境ではローカルAIを優先
8. クラウドAIを使う場合は、実値を除いた相談内容だけを生成
9. 外部送信が必要な場合は停止して明示確認
10. 結果をExcel / CSV / PowerPoint等へ戻しやすい導線を用意
